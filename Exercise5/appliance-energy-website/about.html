About This Project

ApplianceWatt is a demonstration website built as part of a university web development exercise, focused on structuring a multi-page site with HTML, styling it consistently with CSS, and adding interactivity with JavaScript.

Our Purpose

Placeholder text: This site was created to demonstrate core front-end web development skills, including semantic HTML structure, external CSS styling, JavaScript-based interactivity (such as the FAQ accordion and energy calculator), and good version control practice using Git and GitHub.

What You'll Find Here

Home

An overview of appliance energy consumption in Australia, an FAQ section, and an interactive energy calculator.

Televisions

A closer look at television energy usage, comparing screen types and sizes, plus tips for reducing consumption.

About Us

Background on this project, its purpose, and how it was built.

Technology Used

  • HTML5 for page structure
  • CSS3 (external stylesheet) for consistent styling across all pages
  • Vanilla JavaScript for the FAQ accordion and energy calculator
  • Git and GitHub for version control
